## 所見

1. **完全に決定論的**: 全366組(item×qid×model)・5回ずつの試行(計1,830回答相当)で、一致率は**100%**、確信度(probabilities)の標準偏差も**完全にゼロ**だった。モデル・質問型・タスクのどの切り口で見ても例外なし。
2. これは decision モデルの `/v1/systemone` API が(少なくとも Ollama 0.40.14 のこの実装では)サンプリングを行わず、同一入力に対して常に同一の確率分布・同一の回答を返す、実質的に temperature=0 相当の決定論的推論であることを示している。
3. **実務的な示唆**: 「複数回実行して多数決を取る」というロバスト化手法は、*同一の入力・質問文のまま*繰り返しても一切効果がない(常に同じ結果)。Step3-b(言い換え)や Step3-c(選択肢順序)のように、**プロンプト自体を変化させるバリエーション**でしか頑健性を測れない・改善できない。この点は Step3-c の model_routing criteria 改善が効いていた理由(入力そのものを変えている)とも整合する。
